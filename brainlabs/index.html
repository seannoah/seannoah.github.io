CAL POLY · PSY 4480 · COGNITIVE NEUROSCIENCE

Brain Labs

Interactive teaching tools built on my brain scanned at 0.75 mm and reconstructed with FreeSurfer.

VOLUME · 3 PLANES

MRI Explorer

Navigate a real anatomical MRI in sagittal, coronal, and axial planes. This demo includes four label systems, zoom and pan functionality, and a GeoGuessr-style find-the-structure quiz with leaderboards.
SURFACE · FOLDED TO FLAT

Cortex Explorer

Unfold the cortical sheet from folded brain to butterfly flatmap. This demo includes color coding options for different atlases, orientation practice, and a find-the-structure quiz scored by distance along the cortex.
FUNCTION · YEO 7 NETWORKS

Network Explorer

The seven resting-state networks projected onto the cortex. This demo allows you to isolate each network, name its component areas, and read a little bit about what it does, with citations to the primary literature.
NEURON · SPIKES

Action Potential Explorer

Click synapses to inject EPSPs and IPSPs, watch them sum at the axon hillock, cross threshold, and launch a propagating spike. This demo introduces some key concepts about neuron functioning.
GAME · DAILY & ENDLESS

CogNeurdle

Wordle for cog neuro, minus the spelling. Recall the hidden term from five clues, hardest first, in a daily puzzle shared by the whole class or an endless practice run. Term-list and free-recall modes, each with its own class leaderboard.

These demos are designed to work on laptops and phones alike (a bigger screen enables the premium experience).
