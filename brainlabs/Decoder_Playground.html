Decoder Playground

This lab lets you build a tiny fMRI decoding experiment from scratch and watch every step of multivariate pattern analysis (MVPA) happen: you design the true activation patterns for two conditions in a small region of interest, generate noisy trials, split them into training and test sets, train a support vector machine (SVM), and test how well it can read out the condition from brain activity it has never seen.

THE PIPELINE

  1. Patterns. Pick the size of the ROI (a square grid of voxels) and paint the true activation pattern for each condition. Real trials will be noisy copies of these templates.
  2. Dataset. Generate trials. Each trial is one noisy sample of a pattern, with its condition label. Compare the mean activation of the ROI between conditions: that is what a subtraction (univariate) analysis sees.
  3. Split. Set aside test trials whose labels the classifier never sees. Or use cross-validation, where every trial takes a turn in the test set.
  4. Train. The SVM finds a weighted sum of the voxels (a hyperplane) that separates the two conditions in the training set with the widest possible margin. The weight map shows which voxels it relies on.
  5. Test. Apply the trained classifier to the held-out trials and count how often it is right. Run a permutation test to see what accuracy looks like when the labels are meaningless.

GLOSSARY

  • Voxel: a small cube of brain (often 2–3 mm) whose BOLD signal is one number per time point. A 3 mm voxel contains on the order of a million neurons.
  • ROI: region of interest, the set of voxels the analysis looks at.
  • Univariate / subtraction: compare the average activation of a region between conditions. It asks how much a region responds.
  • Multivariate / decoding: use the whole pattern across voxels to predict the condition. It asks whether the region carries information about the condition, even when the average response is identical.
  • SVM: a classifier that learns a weight for each voxel plus an offset; a trial is classified by the sign of the weighted sum. Among all separating hyperplanes it picks the one with the largest margin to the nearest trials (the support vectors).
  • Train / test split: accuracy must be measured on trials the classifier did not learn from, otherwise it can simply memorize noise.
  • Cross-validation: repeat the split so that each fold serves as the test set once, then average the accuracies.
  • Permutation test: shuffle the labels and re-run the whole analysis many times to see the distribution of accuracies you get by chance. Real accuracy is meaningful only if it is unusual under that distribution.
  • Forward vs. reverse inference: subtraction designs run forward (manipulate a mental state, observe brain activity). Decoding runs in reverse (observe brain activity, infer the mental state).

CHALLENGES

  1. Make two patterns with identical mean activation that the decoder still classifies at 90% or better. (Hint: the preset "Same mean, different pattern".)
  2. Make the decoder fail. What has to be true of the two patterns for accuracy to sit at 50%?
  3. At noise 1.0, find the smallest number of trials that still decodes reliably. What happens to the permutation distribution as trials get scarce?
  4. Turn on "test on the training trials" with two identical patterns. Why does accuracy climb above chance when there is no information at all?
  5. Compare the learned weight map with the true difference between templates. When does the SVM recover it, and when does noise dominate?
